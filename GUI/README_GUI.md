# GUI

This folder contains the local interactive interface.

## Main files

- `index.html` — visible page structure and fixed wording
- `static/styles.css` — colours, typography, layout and responsiveness
- `static/app.js` — interactive behaviour and dynamic text
- `static/data.js` — browser-ready projection data
- `data/projections.json` — projection data exposed by the local API
- `server.py` — dependency-free local server
- `models/` — frozen project files and metadata

Use the launchers in the repository root rather than starting this folder
manually.
